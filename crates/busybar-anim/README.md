# busybar-anim

Encoder and decoder for the [BUSY Bar](https://busy.app/) `.anim` animation container, with conversion from GIF, animated WebP and APNG. The container format is described in `lib/anim_file/anim_file_format.h` of the [firmware](https://github.com/busy-app/busybar-firmware).

For the Rust docs, see [docs.rs](https://docs.rs/busybar-anim). Add to your crate by running `cargo add busybar-anim` or adding `busybar-anim` to your dependencies, e.g.

```toml
[dependencies]
busybar-anim = "0.2.0" # check latest version https://crates.io/crates/busybar-anim
```
